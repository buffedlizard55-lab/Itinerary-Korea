# Subway Exit & Elevator Navigation Directory

Korean subway stations are vast underground hubs. Exiting the wrong staircase with heavy luggage wastes time. Use this verified exit directory for top tourist stations.

---

## 2. Navigating with T-money / WOWPASS

* Always check the **yellow illuminated exit signs** hanging from the subway ceiling before exiting the turnstile.
* If you enter the wrong turnstile direction (e.g. northbound instead of southbound), you can call the station master via the **Help button (`도움말`)** on the accessible gate, or tap your card again within 5 minutes at the same station without being charged twice!
